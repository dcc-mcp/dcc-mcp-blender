# blender-photographic-post

This skill creates an owned compositor stack for the photographic toy-shot
finish. It applies halation above `185/255` with warm tint `(1.0, 0.82, 0.62)`
and a `34%` screen blend, adds a gentle RGB S-curve, darkens vignette corners
by `20%`, and adds fine grain whose weight increases in darker pixels.

The default grain tile is regenerated by a Blender frame-change handler, so
live animation frames receive different grain. Pass `grain_sequence_path` when
the scene will be saved and rendered by an isolated Blender worker. The tool
writes a numbered PNG grain sequence and uses compositor auto-refresh so the
worker does not depend on an in-memory handler.

Call `validate_photographic_post` after setup and before a final render.
