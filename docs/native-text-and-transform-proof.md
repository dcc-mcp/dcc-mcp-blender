# Bounded editable text and native transform evidence

This isolated development extension adds create_text and inspect_text for Blender's built-in font only. Creation accepts 1–160 printable ASCII characters, at most three lines, bounded size/extrusion and a closed alignment enum. It refuses existing object/data names and missing materials, verifies native text and formatting, and removes newly created data on failure. It performs no font-file or arbitrary script IO.

The data-geometry inspector additionally returns the actual world matrix, parent inverse and parent name. It reads existing native transform fields; it does not instantiate objects or force dependency-graph evaluation. Callers that need evaluated animation state must first use the existing explicit set_current_frame tool.

Initial source qualification: 24 focused validator/contract tests passed. Actual typed MCP in Blender 4.3.2 with the documented0.1.43-compatible runtime created two native labels, rejected a duplicate without changes, and preserved text/material/geometry across native save/reopen. The original text runtime's formatting-only normalization did not change behavior in that snapshot. A real97-frame four-bar animation probe then read five actual native world matrices at every sampled pose. Maximum hinge closure error was0.000007226413753188325mm in the declared illustration-unit mapping; this is numerical scene closure, not physical metrology. Five native render outputs were produced; production visual review is a separate artifact gate. The saved keys survived reopening.

Current upstream's newer Blender host requirement remains separate. These are explicitly local development capabilities/backports, not claimed as published0.1.43 release features or native acceptance on Blender4.5+. No arbitrary text/font support, evaluated geometry snapshot, driver safety or production-wide scene sanitization is implied.
